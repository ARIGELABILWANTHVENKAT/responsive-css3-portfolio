# Responsive CSS3 Portfolio

A responsive portfolio that adapts to mobile, tablet and desktop screens.

## Features
- CSS Grid for the page layout and project cards
- Flexbox for the navigation and component alignment
- Mobile-first media queries (768px and 1024px)
- Light/dark mode using CSS custom properties, saved between visits
- Respects reduced-motion and system theme settings

## Run locally
Open `task2-responsive-portfolio.html` in your browser.
